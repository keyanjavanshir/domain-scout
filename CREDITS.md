# Credits

domain-scout builds on ideas from these projects and write-ups. No text or code was copied
from them; each idea was re-expressed for this project. Their licenses apply to their own
work. Sources for individual packs are listed in each pack's `sources.md`.

| Source | Idea used here |
|---|---|
| [anthropics/knowledge-work-plugins](https://github.com/anthropics/knowledge-work-plugins) (Apache-2.0) | One package per professional role, each bundling its connectors; packs that are generic until a team customises them, hence the project overlay. |
| [alirezarezvani/claude-skills](https://github.com/alirezarezvani/claude-skills) (MIT) | Per-domain bundles in one repository; interview question banks and sector playbooks; building a knowledge skill from a document collection, hence reading the user's own documents. |
| [VoltAgent/awesome-agent-skills](https://github.com/VoltAgent/awesome-agent-skills) | Skill catalogues as a research source, so packs point to existing skills. |
| [CoEvoSkills](https://arxiv.org/abs/2604.01687) and [SkillGen](https://www.microsoft.com/en-us/research/publication/skillgen-verified-inference-time-agent-skill-synthesis/) | Pairing a skill generator with verification; judging a pack by comparing runs with and without it. |
| [agent-architect](https://github.com/keyanjavanshir/architect) (MIT) | The interview design tree, size limits, and validator-enforced rules. |
| [Agent Skills specification](https://agentskills.io/specification) | The portable SKILL.md format. |
| [Model Context Protocol registry](https://registry.modelcontextprotocol.io) | Finding MCP servers for a field's tools. |
